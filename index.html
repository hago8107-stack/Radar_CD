Radar ultrasónico

Un sensor que convierte el movimiento de un servo y un eco invisible en una lectura visual del espacio.

Cómo funciona

El HC-SR04 viaja montado sobre un servomotor para mirar todo el frente, mientras el Arduino registra cada medición y la envía al monitor serial.

Circuito y componentes

La protoboard organiza la alimentación: el riel positivo lleva los 5V del Arduino y el riel negativo distribuye su GND.

TRIG · 10Disparo ultrasónico
ECHO · 11HC-SR04 → pin digital 11
SERVO · 12Señal del servo → pin digital 12
VCC · 5VHC-SR04 y servo → riel positivo
GNDHC-SR04 y servo → riel negativo
HC-SR04 · el ojo

Emite un pulso ultrasónico y mide cuánto tarda en rebotar contra un objeto y volver. Ese tiempo permite calcular la distancia.

Servomotor · el giro

Tiene el sensor montado encima y lo rota de 0° a 180°, barriendo el frente como la antena de un radar real.

Arduino Uno · el coordinador

Mueve el servo paso a paso, dispara una medición en cada posición y envía el resultado por el puerto serial.

El servo barre 2° cada 30 ms

25 msTimeout del eco

El servo avanza de a 2° desde 0° hasta 180° y regresa; espera 30 ms antes de medir en cada paso. El Arduino mide el tiempo de respuesta con pulseIn y lo convierte a centímetros con la fórmula duración × 0.0343 ÷ 2. Si no llega ningún eco en 25 ms, reporta -1.

El código

Este es el código del circuito armado y simulado en Tinkercad. La simulación web reproduce su barrido y genera registros con el mismo formato: ángulo,distancia. Por ejemplo, 94,37. o 94,-1. si no hay eco.

radar_ultrasonico.inoArduino C++
#include <Servo.h>

const int trigPin  = 10;
const int echoPin  = 11;
const int servoPin = 12;

const int anguloMin = 0;
const int anguloMax = 180;
const int pasoAngulo = 2;
const int retardoServo = 30;
const unsigned long timeoutEcho = 25000;

Servo miServo;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  miServo.attach(servoPin);
  miServo.write(anguloMin);
  delay(500);
}

long medirDistanciaCM() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long duracion = pulseIn(echoPin, HIGH, timeoutEcho);
  if (duracion == 0) return -1;
  return duracion * 0.0343 / 2;
}

void barrer(int desde, int hasta, int paso) {
  for (int angulo = desde; angulo != hasta; angulo += paso) {
    miServo.write(angulo);
    delay(retardoServo);
    long distancia = medirDistanciaCM();
    Serial.print(angulo);
    Serial.print(",");
    Serial.print(distancia);
    Serial.println(".");
  }
}

void loop() {
  barrer(anguloMin, anguloMax + pasoAngulo, pasoAngulo);
  barrer(anguloMax, anguloMin - pasoAngulo, -pasoAngulo);
}
